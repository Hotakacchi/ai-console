## 新しい機能

- **ファイルを読ませる** — 窓にファイルをドラッグ＆ドロップして「要約して」「この表の合計は？」のように頼めます。テキスト・PDF・Word・Excel・PowerPoint・画像に対応しています (`/attach` / `/detach`)。ローカルAIで長いファイルを読むときは先頭の一部だけになります
- **画面を見せる** — 「この画面のエラーは何？」と聞くか `/screen` で、画面を撮って AI に見せます。撮る前に毎回確認します (`/set screen on` / `off`)
- **ローカルAIで画像を読む** — `/install-vision` で部品 (約670MB) を足すと、ネットにつながずに画像や画面を読めます
- インストーラーのファイル名にバージョンを付けました

## New features

- **Read files** — Drop a file onto the window and ask "summarize this" or "what's the total in this table?". Text, PDF, Word, Excel, PowerPoint and images are supported (`/attach` / `/detach`). With the local AI, only the beginning of long files is read
- **Show your screen** — Ask "what is this error on my screen?" or use `/screen`, and Lumi shows a screenshot to the AI. It asks you every time first (`/set screen on` / `off`)
- **Images with the local AI** — `/install-vision` (about 670 MB) lets the local AI read images and screenshots offline
- The installer file names now include the version
