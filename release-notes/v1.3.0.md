## 新しい機能

- **コンソールとして使う** — `!ipconfig` のように `!` を付けると、コマンドを AI を通さずにそのまま実行します。`/shell` でシェルモードになり、打った行がそのままコマンドになります (`cd` での移動も引き継ぎ、`exit` で戻ります)。出力はその場で 1 行ずつ表示され、Ctrl+C で止められます
- **コマンドの単語帳** — よく使う操作の正しいコマンドを AI に教えるようにしました。`/commands` で自分用の単語帳 (`commands.txt`) に「やりたいこと → コマンド」を書くと、AI が優先して使います
- **音声の単語帳** — `/words` で開く `words.txt` に名前や専門用語を書くと、Whisper がその言葉を書き起こしやすくなります
- **確認にアルファベットで答える** — 声で「ワイ」「エー」「エヌ」と答えられます (「イエス」も使えます)

## 修正

- ローカルAIに PC の操作を頼むと「できません」と断られたり、コマンドを出さなかったりする問題を改善
- コマンドがルミのフォルダで実行され、ドライブ全体などを調べられなかった問題を修正 (ホームフォルダで実行し、AI にドライブの一覧を伝えるようにしました)
- コマンドの出力を AI に渡す上限を増やしました (ローカルAI以外)

## New features

- **Use it as a console** — Prefix a line with `!` (e.g. `!ipconfig`) to run it directly without the AI. `/shell` switches to shell mode where every line is a command (`cd` carries over; `exit` to leave). Output streams line by line and Ctrl+C stops it
- **Command phrasebook** — The AI now knows the right commands for common tasks. Add your own "task → command" lines in `commands.txt` (`/commands`) and the AI prefers them
- **Voice vocabulary** — Write names and jargon in `words.txt` (`/words`) so Whisper transcribes them better
- **Answer confirmations with letters** — Say "why" / "a" / "n" (in Japanese: ワイ / エー / エヌ)

## Fixes

- The local AI sometimes refused or didn't propose a command when asked to do something on the PC
- Commands ran in Lumi's own folder, so whole drives couldn't be checked (they now run in your home folder and the AI is told which drives exist)
- More command output is passed to the AI (except the local AI)
