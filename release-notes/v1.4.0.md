## 新しい機能

- **自動アップデート** — 新しい版が出ると起動時にお知らせし、`/update` でダウンロード・入れ替え・再起動まで行います (ダウンロードしたファイルは SHA-256 で確かめます)。今回の v1.4.0 から使えるので、実際に自動で更新されるのは次の版からです
- **ルーティン** — 「おはよう」で今日の天気とリマインダーをまとめて話します。`/routines` で開く `routines.txt` に「仕事モード」などを自分で書けます (開く・実行・言う・AI に頼む)。`[名前 @07:30]` で毎日その時刻に動きます
- **スマホから話しかける** — `/phone` で出る QR コードを同じ Wi-Fi のスマホで読むと、ブラウザから話しかけたり、返事を読み上げてもらったり、確認に答えたりできます (家の中からだけ、鍵つきの URL でだけつながります)
- **顔の演出**
  - コマンドの実行中は顔の中をプログラムが流れ、シェルモードでは顔が `>_` になります
  - Web 検索中は虫眼鏡、ダウンロード中は口がプログレスバーに
  - ファイルを落とすともぐもぐ食べ、画面を撮るとシャッターが光り、覚えると電球が点き、リマインダーではベルが揺れます
  - エラーのときは顔が乱れ (グリッチ)、起動時は古いパソコン風の起動画面、終了時はブラウン管のように消えます
  - 目がマウスを追いかけ、長く放っておくとスクリーンセーバーのように跳ね回ります
  - 「おはよう」の天気に合わせて、サングラス・傘・雪・雲が出ます

## New features

- **Auto-update** — Lumi tells you at startup when a new version is out, and `/update` downloads, replaces and restarts it (verified with SHA-256). It works from v1.4.0, so the first automatic update will be to the next version
- **Routines** — "good morning" tells you today's weather and reminders. Write your own in `routines.txt` (`/routines`) with open / run / say / ai steps; `[name @07:30]` runs it every day at that time
- **Talk from your phone** — Scan the QR code from `/phone` on a phone on the same Wi-Fi to talk, hear replies and answer confirmations in the browser (home network only, with a secret key in the URL)
- **Face effects** — code flows inside the face while a command runs and the face becomes `>_` in shell mode; a magnifier while searching, a progress-bar mouth while downloading, eating dropped files, a camera flash for screenshots, a light bulb when remembering, a ringing bell for reminders, a glitch on errors, a retro boot screen and a CRT power-off, eyes that follow the mouse, a bouncing screensaver, and sunglasses / umbrella / snow / clouds for the weather
