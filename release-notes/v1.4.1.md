## 修正

- **Windows セキュリティに誤検出される問題を修正** — コマンドの実行 (`!`・`/shell`・AI が提案したもの) で、Windows セキュリティに `Trojan:Win32/Wacatac.C!ml` として検出されることがありました。PowerShell を暗号化した形 (`-EncodedCommand`) や実行ポリシーの無視 (`Bypass`) を使わずに動かすようにしました。管理者としての実行と自動アップデートも、同じく怪しく見えない方法に変えました
  - すでに検出されてルミが隔離された場合は、Windows セキュリティの「保護の履歴」から復元してください

## 小さな追加

- **小窓の場所を選べるように** — バックグラウンドで呼んだときに出てくる小窓の場所を `/set peek_position` で選べます (右下・左下・下の真ん中・右上・左上・上の真ん中)。`/peek move` で好きな場所へドラッグして、ダブルクリックで決めることもできます

## Fixes

- **False positive in Windows Security** — Running commands (`!`, `/shell`, or commands proposed by the AI) could be flagged as `Trojan:Win32/Wacatac.C!ml`. PowerShell is no longer started with `-EncodedCommand` or `-ExecutionPolicy Bypass`; running as administrator and auto-update were changed the same way
  - If Lumi was already quarantined, restore it from Windows Security → Protection history

## Small addition

- **Choose where the small window appears** — `/set peek_position` (bottom-right / bottom-left / bottom-center / top-right / top-left / top-center), or drag it anywhere with `/peek move` and double-click to set
