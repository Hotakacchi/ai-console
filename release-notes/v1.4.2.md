## 新しい機能

- **Discord のステータス** — `/discord on` で、Discord のステータスにルミの様子 (「ルミとお話し中」「コマンドを実行中」「Web を調べています」など) を出します。会話の中身は出しません。最初はオフです

## 修正

- 入力中に ← → キーでカーソルを動かせなかった問題を修正 (Home / End、Ctrl+← → で単語ごと、Delete にも対応。文字はカーソルの位置に入ります)
- ダウンロードが途中で切れたりつながらなかったりしたとき、自動で続きから取り直すように (`/update`・`/install-*`)。失敗したときは、手でダウンロードするページも出します
- 自動アップデートのあと、すべてのユーザー用に入れている場合でも、ルミが管理者として起動しないように

## New features

- **Discord status** — `/discord on` shows what Lumi is doing in your Discord status ("Talking with Lumi", "Running a command", "Searching the web", ...). The conversation itself is never shown. Off by default

## Fixes

- The ← → keys couldn't move the cursor while typing (Home / End, Ctrl+← → by word and Delete work too; text is inserted at the cursor)
- Downloads (`/update`, `/install-*`) now retry and resume automatically when the connection fails; on failure the download page is shown
- After an auto-update of an all-users installation, Lumi no longer starts as administrator
