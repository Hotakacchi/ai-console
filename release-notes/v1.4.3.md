## 新しい機能

- **自動モード** — `/auto` か Shift+Tab で、AI が提案したコマンドを確認せずに実行します (タイトルに「auto」と出ます。Ctrl+C でいつでも止められます)。管理者権限が必要なコマンドと、削除・フォーマット・シャットダウン・ダウンロードしたものの実行などの危ない操作は、自動モードでもこれまでどおり確認します

## 修正

- 管理者として実行するときに、PowerShell の窓が出ていた問題を修正

## New features

- **Auto mode** — `/auto` or Shift+Tab runs commands proposed by the AI without asking ("auto" appears in the title; Ctrl+C stops at any time). Commands that need administrator rights and risky ones (deleting, formatting, shutting down, running downloaded scripts, ...) still ask

## Fixes

- A PowerShell window appeared when running a command as administrator
