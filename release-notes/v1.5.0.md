## 新機能

- **タブ** — ターミナルのようにタブを複数開けます。`+` でシェルのタブを開き (`▾` でシェルを選べます)、`×` で閉じます。Ctrl+T / Ctrl+W / Ctrl+Tab でも操作できます
- **シェルを自動で選ぶ** — `/shell` と `!` で使うシェルを PC に合わせて選びます (Windows は PowerShell 7 → Windows PowerShell、macOS / Linux はログインシェル)。cmd・Git Bash・WSL・bash・zsh・fish なども `/shell` で切り替えられます
- **ローカルAIのモデルを選べる** — `/install-local list` でモデルの一覧、`/install-local <名前>` でそのモデルを入れて切り替えます

  | 名前 | サイズ | 特徴 |
  |---|---|---|
  | qwen3.5-0.8b | 約0.5GB | とても軽い |
  | qwen3.5-2b | 約1.3GB | 軽め |
  | qwen3.5-4b | 約2.7GB | 標準 (今までと同じ) |
  | qwen3.5-9b | 約5.7GB | 賢いけど重い |
  | phi-4-mini | 約2.5GB | 英語向け (画像は読めません) |

- **ルミが自分のことを知っている** — バージョン、OS、つないでいる AI、できることを聞くと答えます (オフラインでもバージョンは答えます)

## New

- **Tabs** — open several tabs like a terminal. `+` opens a shell tab (`▾` picks the shell), `×` closes it. Ctrl+T / Ctrl+W / Ctrl+Tab work too
- **Automatic shell choice** — `/shell` and `!` pick the shell for your computer (PowerShell 7 → Windows PowerShell on Windows, your login shell on macOS / Linux). Switch to cmd, Git Bash, WSL, bash, zsh, fish and more with `/shell`
- **Choose the local AI model** — `/install-local list` shows the models, `/install-local <name>` installs one and switches to it (Qwen3.5 0.8B / 2B / 4B / 9B, Phi-4 mini)
- **Lumi knows about itself** — ask for its version, OS, connected AI or features (the version works offline too)
