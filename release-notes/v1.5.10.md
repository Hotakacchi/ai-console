## 新機能

- **監視モード** — `/watch chrome` (または「Chrome が落ちたら教えて」と頼む) で、そのプロセスを見張ります。終わった (落ちた・閉じた)、また起動した、CPU を 1 分くらい使い続けている、メモリが急に増えたときに、顔とメッセージで知らせます (窓が隠れていれば小窓で。声は出しません)
  - `/watch` で一覧、`/watch stop <名前>` (または `all`) でやめます。PID でも見張れます (`/watch 1234`)
  - 名前で見張っているものは、ルミを起動し直しても続きます

## 修正

- **`voice_input` をオフにしても音声入力が止まらなかった** — `/set` で音声まわりの設定 (`voice_input`・`wake_word`・`stt`・`whisper_model`・`language`) を変えても、再起動するまで反映されていなかったのを直しました

## New

- **Watch mode** — `/watch chrome` (or ask "tell me if Chrome crashes") watches that process and tells you, with a face and a message, when it exits (crashed or closed), starts again, keeps a CPU core busy for about a minute, or its memory jumps (the small window pops up if Lumi is hidden; no voice)
  - `/watch` lists them, `/watch stop <name>` (or `all`) stops. PIDs work too (`/watch 1234`)
  - Watches by name continue after restarting Lumi

## Fixes

- **Voice input kept running after turning `voice_input` off** — changing voice settings with `/set` (`voice_input`, `wake_word`, `stt`, `whisper_model`, `language`) now takes effect right away instead of after a restart
