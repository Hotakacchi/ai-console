## 新機能

- **ターミナル版のルミ** — Windows ターミナルの新しいタブのメニュー (`▾`) に「Lumi」が出て、タブの中でルミと話せます (Mac・Linux は `lumi --cli`)。会話・コマンドの実行・`/` コマンド・シェルモードは窓のルミと同じで、顔は `(・‿・)` のような顔文字で表します。声と小窓は窓のルミだけです
- **ドライブで驚く** — USB メモリなどをつなぐと、驚いた顔をして「わっ、ドライブ「…」がつながりました」と知らせます
- **テスト版の目印** — リリース以外のビルドは、バージョンの横に「(テスト)」と出ます

## 修正

- **ターミナルの文字化け** — `wsl` の日本語が化けていたのを直しました。色付きの出力や、`winget` などの進み具合の表示もそのまま読めるようにしました

## New

- **Lumi in the terminal** — "Lumi" appears in the Windows Terminal new-tab menu (`▾`) so you can talk to Lumi inside a tab (`lumi --cli` on macOS / Linux). Chat, commands, `/` commands and shell mode work as in the window; the face is a kaomoji like `(・‿・)`. Voice and the small window stay in the windowed Lumi
- **Surprised by drives** — plugging in a USB stick or another drive makes Lumi look surprised and say which drive connected
- **Test build label** — non-release builds show "(test)" next to the version

## Fixes

- **Garbled terminal output** — Japanese from `wsl` is no longer garbled, and colored output and progress lines (`winget` etc.) are cleaned up
