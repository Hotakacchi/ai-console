## 新機能

- **自作コマンド (プラグイン)** — `/plugins open` で開くフォルダにスクリプトを置くと、ファイル名が `/名前` のコマンドになります (例: `backup.ps1` → `/backup`。続けて書いたものは引数になります)
  - 使えるもの: `.ps1`・`.bat`・`.cmd`・`.exe` (Windows)、`.sh` (Mac・Linux)、`.py` (Python)、`.js` (Node.js)
  - ファイルの最初のコメント行が説明になり、`/help` と `/plugins` に出ます
  - AI も「バックアップして」のように頼まれると使います (実行前に確認します。自動モードなら確認なし)
  - 最初の `/plugins` で、見本の `/hello` が入ります

## New

- **Your own commands (plugins)** — put a script in the folder opened by `/plugins open` and its file name becomes a `/name` command (e.g. `backup.ps1` → `/backup`; anything after it is passed as arguments)
  - Supported: `.ps1`, `.bat`, `.cmd`, `.exe` (Windows), `.sh` (macOS / Linux), `.py` (Python), `.js` (Node.js)
  - The first comment line is its description, shown in `/help` and `/plugins`
  - The AI uses them too when asked (it asks before running, unless auto mode is on)
  - The first `/plugins` adds a sample `/hello`
