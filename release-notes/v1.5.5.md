## 軽くなりました

- **使うときだけ読み込む** — ローカルAI・VOICEVOX・Whisper は使うときに読み込み、1 分使わなければ外してメモリ (と GPU のメモリ) を空けます。起動直後や外れたあとの最初の返事は、読み込む分だけ少し待ちます (「ローカルAIを読み込んでいます…」と出ます)
  - 時間は `/set idle_unload 分` で変えられます。`0` にすると今までどおりずっと読み込んだままです
- **Whisper が数倍速く** — Windows・Linux では [whisper.cpp](https://github.com/ggml-org/whisper.cpp) で書き起こすようにしました。話し終えてから 1 秒ほどで文字になります (8 秒の音声で、small は約 7 秒 → 約 2 秒、base は約 2 秒 → 約 0.6 秒)
  - 前の版で Whisper を入れていた人は、もう一度 `/install-whisper` を打つと速い版になります (それまでは今までの Whisper のまま動きます)。Mac は今までどおりです

## Lighter

- **Load only when needed** — the local AI, VOICEVOX and Whisper load when used and are unloaded after 1 minute unused, freeing memory (and GPU memory). The first reply after starting or after unloading waits a little while it loads ("Loading the local AI…")
  - Change the time with `/set idle_unload <minutes>`; `0` keeps them loaded as before
- **Whisper several times faster** — on Windows and Linux, Whisper now runs on [whisper.cpp](https://github.com/ggml-org/whisper.cpp), turning speech into text about a second after you stop talking (8 s of audio: small ~7 s → ~2 s, base ~2 s → ~0.6 s)
  - If you installed Whisper before, run `/install-whisper` again to get the faster version (until then the old one keeps working). macOS is unchanged
