## 新機能

- **PC に合ったローカルAIを選ぶ** — インストーラーで「ローカルAIもダウンロードする」を選ぶと、PC のメモリと GPU を調べて、重すぎないモデル (0.8B〜9B) を入れます。`/install-local list` では PC の性能と「★おすすめ」が出ます
- **PC の見守り** — CPU やメモリが 1 分くらい 90% を超えたまま (メモリはいちばん使っているアプリの名前も)、ディスクの空きが 10GB を切った、バッテリーが 15% を切ったときに、困った顔で知らせます。窓が隠れていれば小窓で顔を出します (声は出しません。`/set pc_watch off` で止める)

## セキュリティ

- **自動モード** — Web 検索・ページ・付けたファイル・クリップボード・画面など、外から来た文章を AI が読んだあとは、自動モードでもコマンドの前に確認します (文章に仕込まれた指示で勝手に実行されないように。`/cls` で新しい会話にすると元に戻ります)
- **スマホ連携** — スマホから「実行」するときは、PC の画面にだけ出る 4 桁の番号が必要になりました (3 回間違えるとスマホからは答えられなくなります)

## New

- **A local AI that suits your PC** — choosing "Also download the local AI" in the installer now checks memory and GPU memory and installs a model that isn't too heavy (0.8B–9B). `/install-local list` shows the specs and a "★recommended" mark
- **PC watch** — Lumi looks worried and tells you when the CPU or memory stays above 90% for about a minute (naming the app using the most memory), the system disk has less than 10 GB free, or the battery drops below 15%. If the window is hidden, the small window pops up (no voice; `/set pc_watch off` to stop)

## Security

- **Auto mode** — after the AI reads outside text (web search, pages, attached files, clipboard, screen), auto mode asks before running commands, so instructions planted in that text can't run on their own (`/cls` starts a new conversation and turns this off)
- **Phone** — running a command from the phone now needs a 4-digit number shown only on the PC (3 wrong tries locks the phone out of that question)
