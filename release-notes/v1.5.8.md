## 新機能

- **選べるローカルAIが増えました** — `/install-local list` の「ほかのモデル」から、名前を指定して入れられます (`/install-local gemma-3-4b` など)。インストーラーやおすすめで入れるのは、今までどおり Qwen3.5 です

  | 名前 | 大きさ | 特徴 |
  |---|---|---|
  | gemma-3-1b / 4b / 12b | 0.8 / 2.5 / 7.3GB | Google 製 (4B・12B は画像も読める) |
  | gpt-oss-20b | 12.1GB | OpenAI 製。賢いがとても重い |
  | llama-3.2-3b / llama-3.1-8b | 2.0 / 4.9GB | Meta 製。日本語はやや苦手 |
  | mistral-small-24b | 14.3GB | Mistral 製。とても賢いがとても重い |
  | deepseek-r1-8b | 5.0GB | 考えてから答える |
  | swallow-8b | 4.9GB | Llama を日本語向けに鍛えたもの |
  | sarashina-3b | 2.1GB | 日本製。日本語が自然 (PC の操作は苦手) |
  | llm-jp-1.8b | 1.2GB | 日本製。とても軽い (会話向け) |

## 修正

- 大きいファイルのダウンロードが、途中で接続を切られると失敗していたのを直しました (続きから最後まで取ってきます)
- AI の返事が空だったときに、黙らずにそう伝えるようにしました

## New

- **More local AI models** — install them by name from "Other models" in `/install-local list` (e.g. `/install-local gemma-3-4b`): Gemma 3 1B/4B/12B, gpt-oss 20B, Llama 3.2 3B / 3.1 8B, Mistral Small 3.2 24B, DeepSeek-R1 8B, Llama 3.1 Swallow 8B, Sarashina2.2 3B and LLM-jp-3.1 1.8B. The installer and recommendations still use Qwen3.5

## Fixes

- Large downloads no longer fail when the server drops the connection midway (they continue where they stopped)
- Lumi now says so when the AI's reply is empty instead of staying silent
