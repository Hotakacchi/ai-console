## 新機能

- **声でアプリのコマンド** — 「ルミ、コマンド ミュート」「コマンド 自動モード オン」「コマンド 画面 このエラーは何」のように、「コマンド」(または「スラッシュ」) に続けて言うと、/ コマンドを実行します。自作コマンドも呼べます。アップデート・ダウンロード・自動モード・スマホ・終了などは、声で言われたときは確認してから実行します
- **ルミのことは説明書で** — ルミの機能や使い方を聞くと、Web 検索ではなく GitHub のリポジトリの説明書 (README) から関係するところを読んで答えます

## 修正

- **「ルミ」と呼んでも反応しにくかった** — 呼びかけの聞き取りに同じ音の書き方 (ルミ・るみ・留美) を 3 つ入れていたため、確からしさが割れて呼びかけ専用の聞き取りが一度も働いていませんでした。直したので、ずっと反応しやすくなります
- **「ねえルミ」** — 必ず反応するようにしました
- 「ルビー」のような似た言葉では、反応しても取り消すようにしました
- 呼びかけたときに小窓のアニメーションが 2 回動いていたのを直しました
- 返事やコマンドの最中に聞こえた声 (ルミ自身の読み上げも) が、終わったあとに入力されていたのを直しました

## New

- **App commands by voice** — say "command" (or "slash") and then the command, like "Lumi, command mute", "command auto mode on" or "command screen what is this error". Your own plugins work too. Updates, downloads, auto mode, phone, exit and the like ask first when spoken
- **Lumi reads its own manual** — questions about Lumi's features and usage are answered from the README in the GitHub repository instead of a web search

## Fixes

- **"Lumi" was hard to wake** — the wake word listener had three spellings of the same sound, which split its confidence so it never fired. It now responds much more reliably
- **"Hey Lumi"** now always wakes Lumi
- Similar words (like "ruby") are cancelled even if they briefly sounded like "Lumi"
- The small window no longer pops up twice when called
- Speech heard while Lumi was replying or running a command (including Lumi's own voice) is no longer entered afterwards
