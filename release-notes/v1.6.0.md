## 大きな新機能

- **設定画面** — `/settings window` (またはトレイの「設定」) で、すべての設定を画面で変えられます。基本・AI・PC の操作・声・見た目・連携のタブに分かれていて、変えるとすぐ保存して反映します。開いているときだけ窓を作るので、ふだんは軽いままです
- **自動化** — ルーティン (`/routines`) の `[名前 @きっかけ]` に、時刻のほか次のきっかけを書けるようになりました。「USB をつないだら写真をコピーして」と頼むと、AI が書いて、確認してから登録します
  - `@USB` (ドライブをつないだ。`{drive}`)、`@充電`、`@起動`、`@終了:chrome` / `@開始:chrome` (`{app}`)、`@フォルダ:パス` (新しいファイル。`{file}`)
- **長い作業を任せる** — `/task ダウンロードフォルダを種類ごとに整理して` のように頼むと、手順を立ててチェックリストで見せながら、一歩ずつ最後まで進めます (Ctrl+C でいつでも止める。コマンドの確認はふだんどおり)
- **長期の記憶** — 会話を記録しておき、「前に話したあのラーメン屋の名前なんだっけ？」に答えます。`/cls` でも消えません (`/recall 言葉` で探す、`/recall clear` で消す、`/set long_memory off` で記録しない)
- **高精度な音声認識をインストーラーで** — Windows のインストーラーで「高精度な音声認識 (Whisper、約70MB) もダウンロードする」を選べるようになりました。話しかけた内容を正確に書き起こします。ルーティンや自作コマンド、見張っているアプリの名前も聞き取りやすくしました

## そのほかの新機能

- **メモ** — 「メモして: 牛乳を買う」で書き留め、「メモ見せて」で答えます (`/notes`)
- **音楽の操作** — 「次の曲」「一時停止」「音量上げて」「ミュート」で操作します (`/media`)
- **ファイル探し** — 「先週作った Excel どこ？」で、デスクトップ・ドキュメント・ダウンロードなどから探します (`/find 見積 .xlsx 7d`)
- **コピーの履歴** — 最近コピーした文字を 30 件まで覚えておき、「さっきコピーしたURLは？」に答えます (`/clips`。ファイルには保存しません)
- **Mac の Dock** — 窓を隠すと Dock からも消えて、メニューバーのアイコンだけになります

## Big new features

- **Settings window** — `/settings window` (or "Settings" in the tray menu) changes every setting on screen, in tabs (General, AI, PC control, Voice, Look, Connections), saved and applied right away. The window only exists while open, so Lumi stays light
- **Automation** — routines (`/routines`) can now start on triggers, not just times. Ask "copy my photos when I plug in a USB stick" and the AI drafts it and adds it after you confirm
  - `@USB` (a drive was connected; `{drive}`), `@charge`, `@startup`, `@exit:chrome` / `@start:chrome` (`{app}`), `@folder:path` (a new file; `{file}`)
- **Hand over long jobs** — `/task sort my Downloads folder by type` plans the job, shows a checklist and works through it step by step (Ctrl+C stops at any time; commands are confirmed as usual)
- **Long-term memory** — conversations are recorded, so "what was the name of that ramen place we talked about?" works. Survives `/cls` (`/recall <words>` searches, `/recall clear` deletes, `/set long_memory off` stops recording)
- **Accurate speech recognition from the installer** — the Windows installer can also download Whisper (about 70 MB) for more accurate transcription. Names of routines, plugins and watched apps are now easier to recognize

## More new features

- **Notes** — "note: buy milk" writes it down, "show my notes" reads them (`/notes`)
- **Music control** — "next song", "pause", "louder", "mute" (`/media`)
- **File search** — "where's the Excel file I made last week?" searches Desktop, Documents, Downloads and more (`/find invoice .xlsx 7d`)
- **Clipboard history** — remembers the last 30 copied texts and answers "what was the URL I copied a moment ago?" (`/clips`; never saved to a file)
- **macOS Dock** — hiding the window also hides the Dock icon, leaving just the menu bar icon
