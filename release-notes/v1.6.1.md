## 修正

- **同じような答えを何度も繰り返すことがあった** — ほぼ同時に 2 回話しかけられると、同じ質問への返事が 2 つ同時に動いてしまうことがありました。返事を始める仕組みのすき間をなくしました
- AI が同じことを言い直したり、同じ道具 (コマンドなど) をまた使おうとしたら、そこで返事を終えるようにしました
- **ルミの新機能を聞いても答えられなかった** — ルミの機能や使い方を聞くと、説明書 (README) を、「新機能」「最新」なら最新のリリースノートを添えて AI に渡すので、その内容をもとに答えます

## Fixes

- **Lumi sometimes repeated similar answers several times** — two inputs at almost the same moment could start two replies to the same question at once. That gap is closed
- A reply now ends when the AI repeats itself or tries the same tool (command etc.) again
- **Questions about Lumi's new features weren't answered** — questions about Lumi's features and usage now come with its manual (README), or the latest release notes for "what's new", so the AI answers from them
