## 修正

- **版を指定して新機能を聞いても答えられなかった** — 「ルミの v1.6.0 の新機能は？」のように版を指定すると、その版のリリースノートをもとに答えるようにしました。版を指定しないときは、最新の版と、修正だけの版ならその元の版 (v1.6.1 なら v1.6.0) のリリースノートを使います
- 返事に `<br` のような文字が混ざることがあったのを直しました
- 音楽の操作の結果の文 (「音量を上げました」など) を自然な日本語に直しました

## Fixes

- **Asking about a specific version's new features didn't work** — "what's new in Lumi v1.6.0?" now answers from that version's release notes. Without a version, the latest release notes are used, plus the base release (v1.6.0 for v1.6.1) when the latest only has fixes
- Stray text like `<br` no longer shows up in replies
- More natural Japanese for the music control results
