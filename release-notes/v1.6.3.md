## 修正

- **確認の質問で終わった返事のあとに、関係ないコマンドを実行してしまうことがあった** — 「〜しましょうか？」のようにルミが質問して返事を終えたときは、コマンドを実行せずに答えを待つようにしました (自動実行モードでも)
- 返事の中の壊れた `<br` を消すときに、その後ろの文まで消えてしまうことがあったのを直しました
- アップデートをより確実にしました — インストーラーはルミが終わるのを待ってから入れ替えるようにし、ルミが終わらないときは止めてから入れ替えます。ルミの終了処理が止まっても、プロセスが残らないようにしました
- ルミを終了している間に、Discord のステータスが出し直されることがあったのを直しました

## Fixes

- **Lumi sometimes ran unrelated commands after ending a reply with a question** — when Lumi ends a reply by asking you something ("shall I …?"), it now waits for your answer instead of running commands, even in auto mode
- Cleaning up a broken `<br` in replies could remove the rest of the sentence; fixed
- More reliable updates — the installer now waits for Lumi to exit before replacing it, and stops Lumi if it doesn't exit. Lumi's process no longer lingers if shutting down gets stuck
- The Discord status could be set again while Lumi was quitting; fixed
