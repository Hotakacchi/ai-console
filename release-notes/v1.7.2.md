## 新しくなったこと

- **Android (Termux) で使えるように** — [Termux](https://termux.dev/) で次のコマンドを実行すると、ルミのリポジトリが登録されて `pkg install lumi` で入ります。あとは `pkg upgrade` で新しい版になります

  ```bash
  curl -fsSL https://hotakacchi.github.io/ai-console/termux/install.sh | sh
  ```

  - ターミナル版です (声・顔・小窓・画面操作はありません)。対応は aarch64 (64 ビットの ARM) です
  - Claude (`claude-code`)・ChatGPT (`codex`)・API キーで使う AI と話したり、確認してから Termux のコマンドを実行したりできます
  - ローカルAIを使うときは、先に `pkg install llama-cpp` を入れてください (モデルはルミがダウンロードします)
  - リポジトリは署名つきです

## What's new

- **Lumi on Android (Termux)** — run this in [Termux](https://termux.dev/) to add Lumi's repository and `pkg install lumi`; after that, `pkg upgrade` keeps it up to date

  ```bash
  curl -fsSL https://hotakacchi.github.io/ai-console/termux/install.sh | sh
  ```

  - It's the terminal version (no voice, face, peek window or screen control) for aarch64 (64-bit ARM)
  - Talk with Claude (`claude-code`), ChatGPT (`codex`) or an AI with an API key, and run Termux commands after confirming
  - For the local AI, install llama.cpp first with `pkg install llama-cpp` (Lumi downloads the model)
  - The repository is signed
